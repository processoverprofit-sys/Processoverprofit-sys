# Public disclosure checklist

Before publishing, confirm scope, rights to share, pseudonymous commit identity, accurate claims, working links and owner approval. Exclude private source, credentials, wallet details, personal identifiers, internal paths, logs and unpublished findings. Do not post sensitive findings publicly; see [security policy](../SECURITY.md). Public branches and draft pull requests are already visible. Review before uploading, not merely before merging.
