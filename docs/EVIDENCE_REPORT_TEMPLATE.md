# Public evidence report template

**Blank template — no tests, results or independent assurance are recorded here.**

Use only when an actual evidence record has been reviewed and separately approved for public disclosure. Do not attach raw private logs, code, wallets, private paths, internal hashes or credentials. Unknown fields must remain explicitly unknown.

| Field | Value (not yet supplied) |
| --- | --- |
| Public report identifier and date | Not established |
| Project and public requirement | Not established |
| Evidence type (functional test, simulation, paper trading, review) | Not established |
| Scope and non-sensitive environment description | Not established |
| Expected outcome | Not established |
| Observed outcome | Not established |
| Result (pass, fail, blocked, not run, inconclusive) | Not run / no evidence supplied |
| Evidence provenance and review method | Not established |
| Reviewer role and independence limitations | Not established |
| Reproducibility and limitations | Not established |
| Disclosure approval | Not granted |

## Interpretation

Keep expected and observed outcomes separate. Identify failures and unresolved questions. Do not infer independent certification, profitability or production readiness from an isolated test. A simulation or paper result is not live execution performance. A historical development milestone is not a test result.

The private evidence remains private. This template is a reporting structure, not permission to access, execute or disclose any application.

See the [publication checklist](PUBLICATION_CHECKLIST.md) before any proposed report.
