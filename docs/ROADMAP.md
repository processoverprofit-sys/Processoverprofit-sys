# Public development and documentation roadmap

**Scope:** A public communication roadmap, not a private execution plan or an authorisation to operate software.

The purpose of this roadmap is to make development and community-facing documentation easier to follow. It does not expose internal qualification records, operational configuration, private source or release schedules.

## Current project status

| Project | Public position |
| --- | --- |
| T-Bot | Active private development and security qualification. Production readiness and live-money execution are not established or authorised. |
| BrainBot | Historical PC 3.5.0–3.5.3 development line recorded as completed and frozen; no public application release or independent security certification claimed. |
| Engineering HQ | Public engineering portfolio and documentation hub. |

See [T-Bot development status](https://github.com/processoverprofit-sys/T-Bot/blob/main/docs/DEVELOPMENT_STATUS.md) and [BrainBot public overview](https://github.com/processoverprofit-sys/BrainBot).

These milestones describe public documentation work. They are not percentages of software completion or commitments to release dates.

## Research and qualification

T-Bot's public [testing methodology](https://github.com/processoverprofit-sys/T-Bot/blob/main/docs/TESTING.md) describes proposed approaches and fictional examples, not executed test results. Actual qualification, simulated or paper-trading evidence and independent review require separate work and assessment. No public document authorises operational or live-money execution.

BrainBot's historical development-line status is separate from any future public release decision. Additional documentation should distinguish design objectives, historical milestones and supported evidence.

## Future publication principles

Any future public evidence should identify its scope, observed outcomes, limitations and review provenance. Missing evidence must not be represented as a successful test or completed audit.

Private implementation, credentials, wallet information, unpublished security findings, operational configuration and personal identity remain outside the public scope. Publication of any additional material is subject to separate review and approval.

## Community input

The roadmap can evolve in response to useful feedback. Suggestions about missing documentation, test design, architecture clarity and evidence presentation are welcome through the routes in the [community guide](COMMUNITY.md).
