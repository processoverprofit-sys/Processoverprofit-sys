# Frequently asked questions

## Can I download the applications?

No. Both repositories document private applications, not downloadable software.

## Are the projects independently audited?

No independent certification is claimed. Owner-led AI-assisted review is not independent human assurance.

## Can I invest or connect a wallet?

No. T-Bot is not a public investment service; live-money execution is not authorised.

## How can I contribute?

Read the [community guide](COMMUNITY.md) and [contribution policy](../CONTRIBUTING.md). A direct Discord application link is pending. Public pull requests are for non-sensitive documentation corrections only.

## Where is the evidence?

See the [roadmap](ROADMAP.md) and [evidence report template](EVIDENCE_REPORT_TEMPLATE.md). A blank template is not a test result.
